# Дизајн спецификација: Бројач причесника (Црква Свете Тројице)

**Датум:** 24. октобар 2026.  
**Уређај:** Samsung Galaxy Note 10.1 LTE (`GT-N8020`, codename `p4notelte`)  
**ОС:** LineageOS 16.0 (Android 9.0 Pie, API 28)  
**Процесор / Архитектура:** Samsung Exynos 4412 (32-bit `armeabi-v7a`, 2 GB RAM)  
**Писмо и језик:** Српски језик, српска ћирилица  

---

## 1. Сврха и контекст
Апликација служи као дигитална замена и модернизација физичке црквене књиге евиденције броја причешћених верника на Светој Литургији у храму Свете Тројице.

Апликација се користи у литургијском окружењу (певница, олтар, аналој), што намеће специфичне захтеве:
- Мора бити **потпуно бешумна** (никакви звучни сигнали нити аларми).
- Мора имати **дискретну хаптичку повратну спрегу** (вибрација) како би корисник имао тактилну потврду уноса без потребе да стално гледа у екран.
- Екран мора остати активан током трајања причешћа (**Keep Screen On**).
- Естетика мора бити **достојанствена, православно-византијска**, тамнијих тонова како светлост таблета не би одвлачила пажњу у храму.

---

## 2. Архитектура и технички оквир
- **Тип апликације:** Нативна Android апликација (Java / Android SDK API 28).
- **Пакет:** `org.orthodox.communioncounter`
- **Минимална верзија (minSdkVersion):** 21 (Android 5.0 Lollipop)
- **Циљна верзија (targetSdkVersion):** 28 (Android 9.0 Pie)
- **База података:** Локална SQLite база података (`SQLiteOpenHelper`) за трајно офлајн складиштење црквеног Летописа без зависности од екстерних библиотека или интернета.
- **Меморијски отисак:** Екстремно лаган (< 5 MB инсталиран), оптимизован за Exynos 4412 SoC са тренутним одзивом (0ms UI latency).

## 3. Визуелни идентитет (Литургијска тема)
- **Палета боја:**
  - Позадина: Дубока византијска тамно-бордо нијанса (`#2A080C` до `#150305`).
  - Рамови, ивице и нагласци: Литургијско злато / окер (`#D4AF37`, `#F2D06B`).
  - Текст и бројеви: Светло злато / пергамент боја слоноваче (`#FDFBF7`, `#F3E5AB`).
  - Секундарни елементи: Тамни шкриљац (`#1D1315`).
- **Позадински водени жиг:**
  - Обрађена фотографија храма Свете Тројице постављена са 12% транспарентности у позадини главног екрана.
- **Икона апликације:**
  - Православни крст ☦ у златном орнаменту на византијски црвеној подлози.

## 4. Главни екран (Литургијски бројач)
- **Горње заглавље:**
  - Натпис: `ЦРКВА СВЕТЕ ТРОЈИЦЕ`
  - Данашњи датум исписан српском ћирилицом (нпр. *Недеља, 24. октобар 2026.*)
  - Иконица у горњем десном углу: Књига (прелазак на «Летопис причешћених»)
- **Централна тач зона (+1):**
  - Заузима преко 70% екрана таблета.
  - Сваки додир на било ком делу централне зоне увећава бројач за 1.
  - Прати га кратак, нечујан импулс вибро-мотора таблета (35ms).
  - У средини стоји велики златни број са натписом *Причесника*.
- **Зона за исправку (-1):**
  - Доње лево дискретно дугме `[- 1]` са контуром у боји пепела/злата за одузимање у случају грешке.
- **Зона команди (дну екрана):**
  - Дугме **«Заврши и упиши»** (главно златно дугме): Отвара дијалог за архивирање у Летопис.
  - Дугме **«Поништи»** (мање, са дијалогом потврде «Да ли сте сигурни да желите поништити тренутно бројање?» како би се спречио случајан губитак података).

## 5. Летопис причешћених (База података и преглед)
### 5.1 Структура података (SQLite табела `liturgy_records`)
- `id`: INTEGER PRIMARY KEY AUTOINCREMENT
- `timestamp`: INTEGER (UNIX епоха у ms)
- `date_formatted`: TEXT (нпр. "24.10.2026.")
- `day_name`: TEXT (нпр. "Недеља")
- `feast_name`: TEXT (нпр. "Недељна Литургија", "Света Тројица - Духови")
- `count`: INTEGER (број причешћених лица)
- `notes`: TEXT (опционе белешке: свештенослужитељ, појци, напомене)

### 5.2 Дијалог за упис у Летопис
- Појављује се кликом на «Заврши и упиши».
- Приказује коначан број причешћених.
- Предлаже брзе називе службе:
  - «Недељна Литургија»
  - «Празнична Литургија»
  - «Храмовна слава - Света Тројица»
  - «Пређеосвећена Литургија»
  - Опција за ручни унос било ког другог назива.
- Поље за напомену.
- Кликом на «Сачувај», запис се трајно уписује у SQLite базу, а бројач се враћа на 0.

### 5.3 Екран Летописа
- Листа претходних Литургија са свим подацима.
- Збирна статистика на врху (Укупан број причешћених, број одслужених Литургија, просечан број по Литургији).
- Дугме за повратак на бројач.
- Могућност брисања или исправке записа дужим притиском.

1. **Компајлирање:** Израда чистог Release/Debug APK-а помоћу Android SDK алатке (`aapt2`, `javac`, `d8`, `zipalign`, `apksigner`).
2. **Инсталација:** Аутоматска инсталација на прикључени Galaxy Note 10.1 таблет преко `adb install -r`.
3. **Функционални тестови на уређају:**
   - Брзи вишеструки додири (брзо бројање без губитка додира).
   - Тестирање `-1` дугмета.
   - Тестирање хаптичке вибрације без звука.
   - Тестирање уписа у Летопис и перзистентности у бази након поновног покретања апликације.
   - Тестирање будног екрана (Keep Screen On).
